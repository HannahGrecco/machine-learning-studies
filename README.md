# 📈 Sales Revenue Prediction

> 🇧🇷 Prefer reading in Portuguese? Click here: [README.pt-BR.md](README.pt-BR.md)

## About the Project

This project was developed as part of a Machine Learning challenge from Rocketseat.

The objective is to predict the revenue generated by salespeople using Regression techniques based on the following features:

- Experience Time
- Sales Count
- Seasonal Factor

The project covers the complete Machine Learning workflow, including:

- Data loading
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Polynomial Regression model training
- Model evaluation using K-Fold Cross Validation
- Model deployment with FastAPI
- Frontend application with Streamlit

---

## Dataset

The dataset contains **100 records** with no missing values.

| Feature | Description |
|----------|-------------|
| experience_time | Time (in months) that the salesperson has worked at the company. |
| sales_count | Number of sales made during a specific period. |
| seasonal_factor | Seasonal sales factor ranging from 1 to 10. |
| revenue_brl | Total revenue generated by the salesperson (target variable). |

---

## Exploratory Data Analysis

The project includes:

- Dataset inspection
- Missing values verification
- Descriptive statistics
- Histograms
- Scatter plots
- Pairplot
- Correlation matrix

The analysis showed that the independent variables have a very weak linear correlation with the target variable (`revenue_brl`), which directly impacted the predictive performance of the model.

---

## Model

Instead of training a Linear Regression model as an initial baseline, this project directly implements a Polynomial Regression model.

The pipeline includes:

- StandardScaler
- PolynomialFeatures
- LinearRegression

The model is evaluated using **5-Fold Cross Validation**.

Evaluation metrics:

- RMSE
- R² Score
- Residual Analysis
- Residual Normality Test (QQ Plot)

---

The trained model was deployed using:

- FastAPI
- Streamlit

The Streamlit application communicates with the FastAPI endpoint to perform predictions in real time.

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/HannahGrecco/sales-revenue-prediction.git
```

### 2. Install dependencies

Using Pipenv:

```bash
pipenv install
```

### 3. Activate the virtual environment

```bash
pipenv shell
```

### 4. Run the FastAPI server

```bash
uvicorn api_sales_model:app --reload
```

The API will be available at:

```
http://127.0.0.1:8000
```

Swagger documentation:

```
http://127.0.0.1:8000/docs
```

### 5. Run the Streamlit application

```bash
streamlit run app_streamlit_sales.py
```

The application will open at:

```
http://localhost:8501
```
